# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
v2.1. In short: be respectful, assume good faith, and keep disagreements
about code and ideas, not people.

Unacceptable behavior (harassment, personal attacks, discriminatory
language, etc.) can be reported by opening an issue tagged `conduct` or
contacting the repository maintainers directly. Reports will be handled
confidentially.
